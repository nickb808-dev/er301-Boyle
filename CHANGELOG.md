# Boyle — changelog

What changed for players, version by version.

## 0.1.0 — current

- First version: a clean stereo compressor after the WMD MSCL.
  - One `comp` knob for threshold, ratio and makeup together.
  - `att`, `rel`, `gain` and `mix` controls.
  - A `key` branch for sidechain ducking.
  - Range, Makeup limit, detector HPF and Detect options in the menu.
  - An in / reduction / out meter.
- Not yet run on the device.
